## 一、测试环境

| 项目 | 说明 |
|------|------|

## 二、资源名一致性测试

### TC-004-001：三语言资源名集合一致

| 项目 | 内容 |
|------|------|
| **前置条件** | `base/en_US/zh_TW/element/string.json` 均已由 sync 生成 |
| **操作步骤** | 1. 解析三份 string.json 的 name 集合 2. 用 en_US / zh_TW 的 name 集合比对 base 中的语料部分 |
| **预期结果** | en_US 与 zh_TW 的 214 个资源名与 base 语料部分一一对应，无缺译、无多余键 |
| **优先级** | P0 |

### TC-004-002：点号转下划线映射正确

| 项目 | 内容 |
|------|------|
| **操作步骤** | 1. 检索 string.json 中的资源名 |
| **优先级** | P0 |

### TC-004-003：资源名符合鸿蒙命名规范

| 项目 | 内容 |
|------|------|
| **前置条件** | 三份 string.json 已生成 |

## 五、base 默认语言测试

### TC-004-030：未覆盖语言回退 base 中文

| 项目 | 内容 |
|------|------|
| **前置条件** | 系统语言设为语料未覆盖的语言（如 ja-JP） |

| **优先级** | P0 |

### TC-004-031：base 与 zh-CN 语料一致

| 项目 | 内容 |

| **预期结果** | base 中语料条目与 zh-CN 语料一致，默认语言为简体中文 |

## 七、ApiClient 错误 key 测试

### TC-004-050：401 返回未授权 key

| 项目 | 内容 |
|------|------|
| **前置条件** | 后端返回 401（HTTP 或业务 code） |
| **操作步骤** | 1. 触发需要认证的接口调用 |
| **预期结果** | 抛出 `ApiError`，`message === 'message.error.unauthorized'`，展示层显示"登录已过期，请重新登录" |
| **优先级** | P0 |

### TC-004-051：网络异常返回网络 key

| 项目 | 内容 |
|------|------|
| **前置条件** | 断开网络连接 |
| **操作步骤** | 1. 调用任意接口 |
| **预期结果** | 抛出 `ApiError`，`code === -1`，`message === 'message.error.network'`，展示层显示"网络异常，请检查网络连接" |
| **优先级** | P1 |

### TC-004-052：后端业务错误 key 透传

| 项目 | 内容 |
|------|------|
| **前置条件** | 后端返回 `code !== 200` 且 `R.msg === 'message.error.loginFailed'` |
| **操作步骤** | 1. 输入错误密码登录 |
| **预期结果** | `ApiError.message === 'message.error.loginFailed'`，展示层经 `I18n.t` 显示本地化文案 |
| **优先级** | P0 |

### TC-004-053：后端空 msg 兜底 key

| 项目 | 内容 |
|------|------|
| **前置条件** | 后端返回 `code !== 200` 且 `R.msg` 为空 |
| **操作步骤** | 1. 触发该响应 |
| **预期结果** | `ApiError.message === 'message.error.requestFailed'` |
| **优先级** | P1 |

## 八、应用内语言切换测试

### TC-004-060：个人中心「切换语言」入口

| 项目 | 内容 |
|------|------|
| **前置条件** | 已登录进入个人中心 |
| **操作步骤** | 1. 定位「切换语言」按钮 2. 点击 |
| **预期结果** | 弹出选择器，列出简体中文 / English / 繁體中文，当前语言项选中 |
| **优先级** | P0 |

### TC-004-061：切换后即时生效

| 项目 | 内容 |
|------|------|
| **前置条件** | 当前语言为简体中文 |
| **操作步骤** | 1. 打开「切换语言」选择 English 2. 观察个人中心界面 |

| **优先级** | P0 |

### TC-004-062：切换后动态 key 覆盖解析生效

|------|------|

| **优先级** | P0 |

### TC-004-064：默认跟随系统

| **前置条件** | 未在应用内切换过语言，系统语言为英文 |
