## 二、颜色资源一致性测试

### TC-005-001：base 与 dark 颜色名集合一致

| 项目 | 内容 |
|------|------|
| **前置条件** | `base/element/color.json` 与 `dark/element/color.json` 均已落地 |
| **操作步骤** | 1. 解析两份 color.json 的 `name` 集合 2. 比对 dark 的 name 是否为 base 的子集 |
| **预期结果** | dark 中的每个 `name` 在 base 中均存在同名变量，无多余、无缺失核心品牌色/中性色 |
| **优先级** | P0 |

### TC-005-002：变量名映射符合 var.md §8 规则

| 项目 | 内容 |
|------|------|
| **前置条件** | color.json 已落地 |
| **操作步骤** | 1. 检索 color.json 中的资源 name |
| **预期结果** | `--color-primary` → `color_primary`；`--color-text-secondary` → `color_text_secondary`；所有 name 不含 `--`、不含连字符、仅小写/数字/下划线 |
| **优先级** | P0 |

### TC-005-003：品牌主色对齐 var.md

| 项目 | 内容 |
|------|------|
| **前置条件** | base/dark color.json 已落地 |
| **操作步骤** | 1. 读取 `color_primary` 两套取值 |
| **预期结果** | default `#3B5998`、dark `#5B7DB1`，非微信绿 `#07C160`、非 Material 蓝 `#1976D2` |
| **优先级** | P0 |

### TC-005-004：base 保留 start_window_background

| 项目 | 内容 |
|------|------|
| **前置条件** | 原 base 含 `start_window_background` |
| **操作步骤** | 1. 检查改造后 base/element/color.json |
| **预期结果** | `start_window_background` 仍存在，未被核心色收敛覆盖 |
| **优先级** | P1 |

## 三、ThemeManager 三态映射测试

### TC-005-010：system 态映射 COLOR_MODE_NOT_SET

| 项目 | 内容 |
|------|------|
| **前置条件** | 未手动选择过主题 |

| **优先级** | P0 |

### TC-005-012：dark 态映射 COLOR_MODE_DARK

|------|------|
| **前置条件** | 无 |
| **操作步骤** | 1. 调用 `ThemeManager.setMode('dark')` |
| **预期结果** | 使用 `COLOR_MODE_DARK`，强制暗色皮肤 |

### TC-005-013：非法值回退 system

| 项目 | 内容 |
|------|------|
| **前置条件** | StorageService 中 `theme` 为非法值（如 `'foo'`） |

| **优先级** | P1 |

### TC-005-014：isEffectiveDark 三态解析

| 项目 | 内容 |
|------|------|
| **前置条件** | 无 |
| **操作步骤** | 1. 依次 `setMode('dark')`/`setMode('light')` 后调用 `isEffectiveDark()` |
| **预期结果** | dark 返回 true、light 返回 false；system 态返回值与系统深浅一致 |
| **优先级** | P1 |
